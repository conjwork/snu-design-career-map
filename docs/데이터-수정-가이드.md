# 데이터 수정 가이드

교과 내용은 전부 `data/` 안의 자바스크립트 파일에 들어 있습니다.
프로그래밍을 몰라도 **기존 줄을 복사해 값만 바꾸면** 됩니다.
고친 뒤 `index.html`을 새로고침하면 바로 반영됩니다.

주의할 것은 딱 두 가지입니다.

- 따옴표 `"`, 쉼표 `,`, 대괄호 `[ ]`, 중괄호 `{ }`의 짝을 맞출 것
- **id는 다른 항목과 겹치지 않게** 할 것 (id는 화면에 보이지 않는 내부 이름)

고치고 나서 화면이 하얗게 비면 문법이 깨진 것입니다.
브라우저에서 `F12 → Console`을 열면 몇 번째 줄이 문제인지 알려줍니다.

## 1. 학부 과목 고치기

`data/undergraduate-courses.js`

```js
c("v-typo","타이포그래피","Typography",3,"2-1","vd-c",
  {core:1, nw:1, was:"타이포그래피디자인1", tag:["타이포","그래픽"]}),
```

| 자리 | 뜻 | 예 |
|---|---|---|
| 1 | id — 내부 이름, 겹치면 안 됨 | `"v-typo"` |
| 2 | 국문 강좌명 | `"타이포그래피"` |
| 3 | 영문 강좌명 | `"Typography"` |
| 4 | 학점 | `3` |
| 5 | 개설 학기 | `"2-1"` (2학년 1학기) |
| 6 | 표에서 들어갈 열 | `"vd-c"` |

**6번 열 코드**

| 코드 | 열 |
|---|---|
| `vd-g` | 시각디자인 · 그래픽 |
| `vd-c` | 시각디자인 · 코어 |
| `vd-m` | 시각디자인 · 미디어 |
| `cm` | 공통교과목 |
| `id-p` | 산업디자인 · 제품 |
| `id-c` | 산업디자인 · 코어 |
| `id-s` | 산업디자인 · 공간 |

**7번 선택 항목** (필요한 것만 적으면 됩니다)

| 키 | 뜻 |
|---|---|
| `core:1` | 핵심이수 과목 |
| `req:1` | 전공필수 |
| `art10:1` | 미술대학 공통 10과목 |
| `eng:1` | 영어진행 강의 |
| `nw:1` | 2026 개편으로 신설·개명 |
| `was:"옛 이름"` | 변경 전 강좌명 |
| `both:1` | 1·2학기 모두 개설 |
| `cap:"루트id"` | 졸업전시 스튜디오 |
| `tag:["타이포","그래픽"]` | 역량 태그 (진로 필터에 쓰임) |

### 과목 설명 한 줄

같은 파일 아래쪽 `WHY` 목록에서 고칩니다. 루트맵에 회색 글씨로 나오는 문장입니다.

```js
const WHY={
  "v-typo":"글자를 다루는 기본 문법. 시각 전공의 뼈대.",
  ...
};
```

### 핵심이수 · 선택이수 목록

같은 파일의 `CORE_2024`, `SEL_2024`에 과목 id를 넣고 빼면 됩니다.

## 2. 진로 고치기

`data/undergraduate-careers.js`

```js
J("uxpm","MIX","UX 디자이너 (프로덕트)",
  "행동을 조사해 화면과 사물을 동시에 설계.",
  "네이버·카카오·삼성 UX조직, 프로덕트 스타트업",
  ["c-research","v-ui","v-iid","v-suxd","i-hbd","i-psd"],
  ["c-process","c-ai","c-dtr","i-intel"],
  ["uiux","pi"],
  "HCI · 인터랙션디자인(정의철/윤주현)"),
```

| 자리 | 뜻 |
|---|---|
| 1 | id |
| 2 | 계열 — `VD` 시각형 / `ID` 산업형 / `MIX` 복합형 / `THEORY` 이론·연구형 |
| 3 | 진로 이름 |
| 4 | 한 줄 설명 |
| 5 | 주로 가는 곳 |
| 6 | **꼭 필요한 과목 6개** (과목 id) |
| 7 | 여유되면 들을 과목 |
| 8 | 도착지 졸업전시 루트 id |
| 9 | 대학원 연계 안내 |

6·7번에 적는 과목 id는 `undergraduate-courses.js`에 실제로 있어야 합니다.
없는 id를 적으면 그 과목만 화면에서 조용히 빠집니다.

### 진로를 새로 추가할 때

`CAREERS` 배열 안 아무 곳에나 한 줄 추가하면 됩니다.
계열별 개수는 자동으로 다시 세어집니다.

## 3. 졸업전시 루트 고치기

같은 파일 `ROUTES`

```js
{id:"graphic", name:"그래픽디자인", side:"VD", col:"vd-g",
 line:"타이포그래피와 출판을 축으로 한 정통 그래픽 트랙.",
 feed:["v-basic","v-typo","v-typom","v-comp","v-gen","v-pub","v-illust","v-3d"],
 concepts:[
   ["타이포 실험","글자 자체를 주제로 삼는 실험",["v-typo","v-typom","v-comp"]],
   ...
 ]},
```

- `side` — `VD` 또는 `ID`
- `feed` — 이 루트로 가는 선행 과목. **학기 순서대로** 적어야 흐름도가 자연스럽습니다
- `concepts` — 세부 컨셉 4개. 각각 `[이름, 설명, 관련 과목 3개]`
- 스튜디오 과목(`cap`)은 자동으로 붙습니다. `undergraduate-courses.js`에서
  `cap:"graphic"`이 달린 과목을 찾아 연결합니다

### 담당 교수

`data/faculty.js`의 `ROUTE_PROF`에서 루트 id별로 이름을 적습니다.

```js
graphic:["김경선","Chris Hamamoto"],
```

이름은 같은 파일 `PROFS`에 있는 것과 정확히 같아야 상세 정보가 따라옵니다.

## 4. 대학원 고치기

`data/graduate.js`

대학원 표는 **8칸** 구조입니다. 과목마다 어느 칸에 나올지를 배열로 적습니다.

| 칸 코드 | 뜻 |
|---|---|
| `MS1` `MS2` | 석사 · 스튜디오 트랙 · 1 / 2학기 |
| `MT1` `MT2` | 석사 · 논문 트랙 · 1 / 2학기 |
| `DS1` `DS2` | 박사 · 스튜디오 트랙 · 1 / 2학기 |
| `DT1` `DT2` | 박사 · 논문 트랙 · 1 / 2학기 |

```js
g("g-s11","디자인스튜디오 11","Design Studio 11",["MS1","DS1"],"gid",
  {studio:1, prof:"정의철", why:"UX · HCI디자인 방향의 작품 연구."}),
```

한 과목이 여러 칸에 나오면 배열에 전부 적습니다.
예를 들어 강독 과목은 스튜디오 트랙과 논문 트랙 양쪽에 열리므로 `["MS1","MT1"]`입니다.

**열 코드**: `gid` 산업디자인 / `gvd` 시각디자인 / `gdhc` 디자인역사문화 / `gcm` 공통

**선택 항목**: `studio:1` 스튜디오 과목 / `thesis:1` 대학원논문연구 / `prof:"이름"` 담당 교수 / `deg:"석사"` 과정 표시

### 학위연구 트랙

`GROUTES`의 `track`이 `"S"`면 스튜디오 칸(MS·DS), `"T"`면 논문 칸(MT·DT)을 씁니다.
`feed`에 적은 과목이 그 트랙 칸에 없으면 흐름도에서 빠지니 주의하세요.

## 5. 색과 여백 고치기

`assets/styles.css` 맨 위 `:root`에 색 토큰이 모여 있습니다.

```css
--vd:#C4126B;   /* 시각디자인 */
--id:#0B57C4;   /* 산업디자인 */
--dh:#1B7A4B;   /* 대학원 디자인역사문화 */
```

이 세 개 말고는 전부 무채색입니다. 색을 늘리기보다 이 규칙을 지키는 편을 권합니다.
