# 서울대학교 미술대학 디자인과 진로맵

학부·대학원 교과과정과 졸업 후 진로를 이어 보는 인터랙티브 맵입니다.
과목 하나하나를 눌러 담아 가면서 "이 진로로 가려면 몇 학년에 뭘 들어야 하는지"를 확인할 수 있습니다.

빌드 도구도, 패키지 설치도 없습니다. `index.html`을 브라우저로 열면 바로 돌아갑니다.

---

## 화면 구성

| | 화면 | 내용 |
|---|---|---|
| 01 | 교과과정표 | 학생생활안내 4-1과 같은 배치. 학부 / 대학원 표를 버튼으로 전환 |
| 02 | 진로 구분표 | 계열별 진로 목록, 계열 설명, 교수진 |
| 03 | 졸업전시 구분표 | 8개 스튜디오 루트, 규정, 담당 교수, 세부 컨셉 |
| 04 | 교과 루트맵 | 진로 / 졸업전시 / 대학원연계 세 갈래 |

왼쪽 위 **학부 · 대학원** 버튼으로 전체를 대학원 기준으로 바꿀 수 있습니다.
대학원 모드에서는 03이 학위연구 구분표, 04 하위가 진로 / 학위연구 / 지도교수로 바뀝니다.

색은 두 가지만 의미를 가집니다. **자홍 = 시각디자인**, **파랑 = 산업디자인**.
복합형은 두 색을 반씩 나눈 사각형, 대학원 디자인역사문화는 초록입니다. 나머지는 전부 무채색입니다.

## 실행

### 그냥 열기
`index.html`을 더블클릭하면 됩니다. 서버가 필요 없습니다.

### 로컬 서버 (선택)
```bash
python3 -m http.server 8000
# http://localhost:8000
```

### GitHub Pages로 공유
저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 로 두면
`https://<계정>.github.io/<저장소>/` 에서 바로 열립니다. 별도 설정 파일은 필요 없습니다.

## 파일 구조

```
.
├── index.html                      화면 뼈대. 사이드바와 빈 본문만 들어 있음
├── assets/
│   └── styles.css                  전체 스타일. 색 토큰은 파일 맨 위 :root
├── data/                           ← 교과 내용을 고칠 때 보는 곳
│   ├── undergraduate-courses.js    학부 과목 76개, 표 열 구조, 핵심/선택이수 목록
│   ├── undergraduate-careers.js    졸업전시 루트 8개, 진로 42가지, 역량 태그
│   ├── faculty.js                  교수진 11명, 루트별 담당 교수
│   └── graduate.js                 대학원 과목 51개, 학위연구 트랙 5개, 진로 18가지
├── src/
│   └── app.js                      화면을 그리는 로직. 교과 내용은 여기 없음
├── check-data.js                   데이터 오류 검사기 (node check-data.js)
└── docs/
    ├── 데이터-수정-가이드.md        과목·진로·루트를 추가하고 고치는 법
    └── 확인이-필요한-항목.md        원본 PDF에서 확정하지 못한 부분 목록
```

**교과 내용을 고칠 때는 `data/` 안의 파일만 보면 됩니다.** `src/app.js`는 표시 방식만 다룹니다.
자세한 방법은 [docs/데이터-수정-가이드.md](docs/데이터-수정-가이드.md)를 보세요.

## 출처와 한계

- 학부·대학원 **NEW 교과과정 맵 (2026.08.06. 수정)**
- **2025학년도 학생생활안내 (학부)**

교과과정표의 열 구조는 학생생활안내 4-1을, 강좌명과 학점은 개편 맵을 따랐습니다.

다만 아래는 **확정하지 못한 채 추정으로 채운 부분**이 있습니다.

1. 개편으로 신설·개명된 과목의 **학기와 도메인 배치** (화면에서 `변경` 표시가 붙은 과목)
2. 대학원 디자인스튜디오 **21 · 41 · 71 · 81 · 91과 시각디자인 교수 5인의 개별 대응**
3. **진로 42가지 / 18가지의 분류와 과목 조합** — 편집자가 정리한 것으로, 학과의 공식 진로 구분이 아닙니다

전체 목록은 [docs/확인이-필요한-항목.md](docs/확인이-필요한-항목.md)에 있습니다.
아는 분이 고쳐 주시면 가장 도움이 됩니다.

> 수강신청과 졸업 판정은 반드시 마이스누 수강편람과 학과 공지를 확인하세요.
> 이 맵은 참고용이며 학과의 공식 자료가 아닙니다.

## 같이 고치기

1. 저장소를 fork 하거나 브랜치를 만듭니다
2. `data/` 안의 해당 파일을 고칩니다
3. `index.html`을 브라우저로 열어 화면이 깨지지 않는지 확인합니다
4. `node check-data.js`를 돌려 오류가 없는지 봅니다 (선택, Node.js 필요)
5. Pull Request를 보냅니다 — **무엇을 무슨 근거로 고쳤는지** 한 줄 적어 주세요

```
$ node check-data.js

오류 없음

학부 과목 76 · 루트 8 · 진로 42
대학원 과목 51 · 트랙 5 · 진로 18
```

오타로 없는 과목 id를 적거나, 대학원 과목을 잘못된 트랙에 넣으면 여기서 잡힙니다.
PR을 올리면 GitHub Actions가 같은 검사를 자동으로 돌립니다.

교과 내용 오류만 알려주셔도 됩니다. Issues 탭에 `교과과정 오류 신고` 템플릿이 있습니다.
